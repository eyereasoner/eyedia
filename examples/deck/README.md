# Example decks

![EYE](https://josd.github.io/images/eye.png)

*Eyedia — reasoning you can see.*

Each example comes with a short card deck that explains it for a wide audience: the question it asks, what the program says, what Eyedia concludes, why, and what the proof checker confirms. Cards are separated by `---`, so a deck reads as plain Markdown here and works as slides in Markdown slide tools such as Marp.
